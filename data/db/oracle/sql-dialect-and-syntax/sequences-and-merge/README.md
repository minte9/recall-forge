# DB / Oracle / SQL Dialect & Syntax / Sequences & MERGE

## 1. Sequences: NEXTVAL & CURRVAL

Oracle sequences use dot-notation -- `seq_name.NEXTVAL` and
`seq_name.CURRVAL` -- rather than a function call like Postgres's
`nextval('seq_name')`. `CURRVAL` returns the value most recently
generated by `NEXTVAL` *in the current session*, so it's safe from races
with other sessions inserting concurrently.

```sql
CREATE SEQUENCE order_seq START WITH 1 INCREMENT BY 1;
INSERT INTO orders (id, total) VALUES (order_seq.NEXTVAL, 99.90);
SELECT order_seq.CURRVAL FROM DUAL;
```

## 2. MERGE for Upsert

`MERGE INTO target USING source ON (condition) WHEN MATCHED ... WHEN NOT
MATCHED ...` is the standard-SQL upsert statement Oracle popularized --
one statement handling both the update and insert branches, compared to
MySQL's `ON DUPLICATE KEY UPDATE` or Postgres's `ON CONFLICT`, which are
each engine-specific shorthand for the same idea.

```sql
MERGE INTO inventory i
USING (SELECT 'ABC' sku, 5 qty FROM DUAL) s
ON (i.sku = s.sku)
WHEN MATCHED THEN UPDATE SET i.qty = i.qty + s.qty
WHEN NOT MATCHED THEN INSERT (sku, qty) VALUES (s.sku, s.qty);
```
